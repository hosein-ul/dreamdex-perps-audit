<h2 id="chains">Chains</h2>
<p>Use the chain definitions that <code>@somnia-chain/markets-sdk/chains</code> exports. Each one carries its WebSocket URL, so <code>wsRpcUrl</code> is optional with them. If you use them, set <code>wsRpcUrl</code>.</p>

<p>The mainnet and Shannon testnet constants share the protocol contracts (<code>binaryModule</code>, <code>binaryPoolBeacon</code>, <code>binaryPoolImpl</code>, <code>marketsCore</code>, <code>oracleHub</code>, <code>binarySettlement</code>, <code>clobFactory</code>, <code>collateralRouter</code>, <code>marketCreatorFactory</code>) and differ in <code>collateral</code>, <code>marketCreator</code>, <code>lend</code>, <code>perpPoolFactory</code>, <code>marginBank</code>, and <code>priceFeedScheduler</code>.</p>
<p>The Hideki preset omits <code>collateralRouter</code> and <code>lend</code>. Hideki has no wSTT,
Permit2, or SomniaLend deployment, so the corresponding helpers report
not-configured.</p>
<p>The Hideki indexer is development-grade. It runs in the development environment
and has no alerting, so a stall can go unnoticed. It indexes the Hideki binary,
perp and spot markets, except the HBTT/USDso spot pool. Omit <code>indexerUrl</code>
for chain-only reads and writes; supply one for indexed discovery and history.
Indexed reads without a configured URL fail with <code>NotConfiguredError</code>; requests
to an unreachable indexer fail with <code>IndexerError</code>.</p>
<p>The Shannon and Hideki presets set <code>perpPoolFactory</code> and a candidate <code>marginBank</code>.
These values come from the canonical perp deployment records. With Multicall
and a modern factory, discovery takes at most two serial rounds when every pool names
the candidate bank. Each pool&#39;s own bank controls its registration gate.
Unknown or different banks use authoritative fallback reads.
<code>loadMarkets</code> therefore
lists their perps from the chain, also when the binding has no <code>indexerUrl</code>.
The mainnet preset has neither perp field because its deployment is deferred.</p>

<p>These are two separate deployments. Each one indexes the <code>PriceFeedScheduler</code>
on its own chain. Use the feed that matches the chain the client runs on. A
mainnet client that uses the testnet feed reads prices from chain 50312.</p>
<p>The mainnet feed carries fewer symbols than the testnet feed. Code written for
the testnet asset list can therefore fail on mainnet. Read the feed catalog to
learn which bases exist. A base the feed does not carry returns no rows. It does
not raise an error.</p>
<p>The <code>PriceFeedScheduler</code> contract is at
<code>0x7ccAE31E45693475be1e4BAa2360D6997eB2D32B</code> on Shannon, and at
<code>0x1998C88D54a240b8C671493f27f58eC416b81D7F</code> on mainnet and on Hideki. It holds
every price under a symbol name, and the perp pools&#39; oracles read it. The Shannon
and Hideki address constants set it as <code>priceFeedScheduler</code>. The mainnet constant
